# 0002. JSON-слой: Writer со стейт-машиной и подменяемые Sink

**Контекст.** JSON был распылён: каждый класс сам собирал массив, сам проверял
поля и сам решал, как печатать. Хотелось симметрии с бинарным слоем
(`DnsReader`/`DnsWriter`), при этом с возможностью писать сразу в поток.

**Решение.**
- `JsonWriter` — единственное место, где живёт структура: порядок полей, запятые,
  отложенные ключи, пропуск пустых контейнеров.
- `JsonSink` — приёмник: `JsonArraySink` (вложенные массивы), `JsonStreamSink`
  (поток с буфером, он же строковый приёмник).
- `JsonReader` — валидатор поверх `json_decode`: типы, значения по умолчанию,
  путь до поля в сообщении об ошибке.
- `trait JsonPacket` — общий контракт `writeToJson`/`fromJsonReader` и обёртки
  `toJson()`, `toJsonString()`, `toJsonStream()`.

**Почему Reader не потоковый.** DNS-сообщения малы, узкое место — сам `json_decode`;
в PHP нет потокового JSON-парсера, а pull-модель потребовала бы переписать разбор
всех классов. Читатель можно заменить позже, не меняя вызывающий код.

**Не делать.** Не собирать JSON вручную в модельных классах; не добавлять состояние
(запятые, ключи) в `JsonSink` — оно должно оставаться в `JsonWriter`.
