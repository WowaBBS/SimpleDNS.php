# 0005. NetBIOS — отдельный клиент, вне DNS-модели

**Контекст.** NetBIOS Name Service (UDP 137) похож на DNS конвертом, и хотелось
переиспользовать `DnsMessage`/`DnsRecord`.

**Проверено на живом пакете.**
- имена 16 байт (15 символов + суффикс) кодируются 32 символами со сдвигом `'A'`;
- в ответах `QDCOUNT = 0` — вопрос не повторяется;
- типы `0x20` (NB) и `0x21` (NBSTAT), причём `0x21` совпадает с DNS `SRV`;
- RDATA у NBSTAT — таблица имён с выравниванием нулями;
- флаги — `NM_FLAGS`, а не DNS-флаги.

**Решение.** `NbnsClient` отдельным классом: `stat()` (NBSTAT) и `resolve()` (NB).
Переиспользуется только `DnsReader` для разбора конверта. Пакет собирается вручную
через `pack()`; в TODO записан вариант B — сборка через будущий `DnsBuilder::message()`.

**Не делать.** Не добавлять NBNS в `DnsRecord`/`RdataRegistry`/`DnsMessage`:
коллизия типов и другая семантика флагов сделают модель неверной.
