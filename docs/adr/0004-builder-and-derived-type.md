# 0004. DnsBuilder и вывод типа из класса RDATA

**Контекст.** Сборка сообщения в тестах занимала 4–5 строк, а тип записи дублировал
класс данных: `new DnsRecord('example.com', 15, 1, 3600, new MxRecord(...))` — при
ошибке в числе получалась запись с чужим типом.

**Решение.**
- `DnsRecord::__construct(string $name, DnsRdata $rdata, int $ttl = 0, int $class = 1,
  ?int $type = null)`: тип выводится через `RdataRegistry::typeFor()`, явный код
  требуется только для `UnknownRdata`, несоответствие — исключение.
- `DnsBuilder` — заготовки (`request`/`response`), дефолты (`ttl`, `class`), секции
  и сахар по типам (`a`, `mx`, `txt`, `soa`, …).

**Следствия.** Число конструкторов записей в тестах упало с 72 до 8; «тип не
соответствует данным» стало невозможным.

**Не делать.** Не возвращать позиционный `$type` вторым аргументом и не собирать
`DnsRecord` вручную там, где хватает билдера.
