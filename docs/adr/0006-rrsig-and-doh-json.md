# 0006. RRSIG как тип 46 и DNSSEC в DoH JSON

**Контекст.** JSON-канал dns.sb для подписанных зон возвращал RRSIG (`Type=46`)
в презентационном виде. Разбор падал: неизвестный тип читается только как
`\# <длина> <hex>` (RFC 3597).

**Решение.**
- `RrsigRecord` — полноценный тип 46: wire-структура RFC 4034, разбор текста
  с датами из 14 цифр UTC и base64-подписью.
- В JSON DNSSEC запрашивается параметром `do=1`: `DohTransport::jsonUrl()` добавляет
  его, если в запросе есть OPT с флагом DO (в JSON-канале бит DO не передаётся).
- `Accept: application/dns-json` — единственное значение, которое принимают
  Cloudflare, Google и dns.sb (Cloudflare на `*/*` отвечает 400).
- Мнемоники типов и ключи JSON читаются без учёта регистра: Google с `do=1`
  присылает `"type": "a"`.

**Не делать.** Не пропускать молча записи, которые не удалось разобрать: лучше
понятное исключение, чем тихая потеря данных.
