# AGENTS.md — как работать с SimpleDNS.php

Короткая инструкция для ИИ-агентов: что запускать, чего не ломать, где что лежит.
Подробности — в `docs/`.

## Что это

`SimpleDNS.php` — DNS-клиент на чистом PHP без зависимостей: свой wire-кодек,
свой JSON-кодек, транспорты (DoH, UDP, TCP, DoT, mDNS, LLMNR), сборка сообщений
через `DnsBuilder` и отдельный клиент NetBIOS.

Чего здесь нет и не должно появиться без прямой просьбы: composer, автозагрузки,
namespace, PSR-4, сторонних библиотек.

## Запуск

Нужен PHP 8.1+ (проверялся на 8.5) с `short_open_tag=On`. Если `php` нет в `PATH`,
подставьте путь к своему интерпретатору — в проекте он нигде не зашит.

```bash
cd src/DNS
php Test.php8            # офлайн-набор, ожидается «0 упало»
php Test.Network.php8    # живой прогон, нужна сеть: PASS/FAIL плюс блок NOTE
```

Живой набор в офлайн-прогон не входит: он ходит в сеть и зависит от провайдеров.

## Три вещи, которые ломают больше всего

1. **Кодировка.** Код в cp1251 + LF. Инструмент, который пишет UTF-8, испортит
   кириллицу в комментариях и названиях тестов. Документация (`*.md`) — наоборот,
   в UTF-8, чтобы её читали GitHub и инструменты.
2. **`<?` вместо `<?php`.** Работает только при `short_open_tag=On`. Перезаписывая
   файл целиком, не теряйте этот тег.
3. **Табличное выравнивание.** `=`, `=>`, запятые и `::` выровнены в колонки — это
   стиль проекта, а не случайность. Не «нормализуйте» обратно.

## Карта проекта

| Путь | Роль |
|---|---|
| `src/DNS/_All.php` | манифест: подключает всё в правильном порядке |
| `src/DNS/Binary/` | `DnsReader` (единственное чтение байтов), `DnsWriter` (единственная запись), трейт `Packet` |
| `src/DNS/Codec/` | `NameCodec` (имена), `StrCodec` (экранирование), `NameTable` (сжатие), `Json/` (свой JSON-кодек) |
| `src/DNS/Record/` | `DnsRdata` и типы записей, `RdataRegistry` (тип → класс) |
| `src/DNS/List/` | `DnsList` и списки секций (`DnsQuestionList`, `DnsRecordList`) |
| `src/DNS/Header.php`, `Question.php`, `Record.php`, `Message.php` | слои сообщения |
| `src/DNS/Builder.php` | `DnsBuilder`: короткая сборка сообщений |
| `src/DNS/Transport/` | `DnsTransport` и реализации: DoH, UDP, TCP, DoT, DoQ (заглушка), mDNS, LLMNR, фабрика |
| `src/DNS/Nbns.php` | `NbnsClient` — NetBIOS Name Service, намеренно вне DNS-модели |
| `src/DNS/Test.php8` | офлайн-раннер; тесты живут в классах (`static function test(TestRunner $t)`) |
| `src/DNS/Test.Network.php8` | живой прогон транспортов |
| `src/DNS/Example*.php8` | запускаемые примеры и утилиты |

## Инварианты, которые нельзя обходить

- Байты читает только `DnsReader`, пишет только `DnsWriter`. Не собирайте пакеты
  через `pack()` там, где есть писатель.
- JSON собирает `JsonWriter`, разбирает `JsonReader`. Не пишите `json_encode` вручную
  в модельных классах.
- Имена проходят только через `NameCodec`, типы — только через `RdataRegistry`.
- Секции сообщения — объекты `DnsList`: `count()`, `foreach`, `[]=` работают,
  `array_*` — нет (есть `toArray()`).
- Счётчики в заголовке вычисляются при записи из фактического содержимого.
- EDNS (OPT) есть только в DNS: в mDNS, LLMNR и NBNS его быть не должно.

## Запрещено без прямой просьбы

- переводить код в UTF-8, менять LF на CRLF, добавлять BOM;
- добавлять composer, namespace, автозагрузку, PHPUnit;
- добавлять `declare(strict_types=1)` в обычные классы (он есть только в `_All.php`);
- менять порядок `Include_Once` в `_All.php` без причины;
- «улучшать» выравнивание колонок;
- править `docs/known-limitations.md` в сторону «починил», не проверив живьём.

## Перед коммитом

1. `php -l` по изменённым файлам.
2. `cd src/DNS && php Test.php8` — `0 упало`.
3. Если менялись транспорты — `php Test.Network.php8`.
4. Если добавлялся тип записи — он должен попасть в `RdataRegistry`, в `_All.php`,
   в `DnsMessage::TYPE_NAMES` и в цикл «JSON → wire» в `Message::testJson`.
