Нужно написать DnsReader, который бы выполнялся для десериализаии и контроллировал чтение и выдавал эсепшн, если данные прочитать нельзя, deserialize(string $buf) оставить. он должен создавать DnsReader для работы тестов.

Идея правильная: сейчас проверка границ размазана по куче `substr` и `unpack`-ов, а с `DnsReader` весь контроль чтения живёт в одном месте. Делаю так: `DnsReader` - единственное место, которое трогает байты при разборе; все статические `deserialize(string $buf)` сохраняют сигнатуры (для обратной совместимости с уже написанными тестами) и внутри создают ридер, а рядом появляется `fromReader(DnsReader ...)` - его и можно дёргать напрямую в тестах.

## Новый класс DnsReader

Добавьте в `doh_client.php` (до всех остальных классов - они его используют):

```php
/* ============================================================
 * DnsReader - контролируемое чтение бинарного DNS-сообщения.
 * Единственная точка доступа к байтам при десериализации:
 * любое чтение за границей буфера бросает исключение.
 * ============================================================ */

final class DnsReader
{
  public function __construct(
    private string $buf,
    private int  $off = 0,
  ) {}

  public static function of(string $buf, int $off = 0): self
  {
    return new self($buf, $off);
  }

  public function tell(): int    { return $this->off; }

  public function remaining(): int { return strlen($this->buf) - $this->off; }

  public function eof(): bool    { return $this->off >= strlen($this->buf); }

  public function seek(int $off): void
  {
    if ($off < 0 || $off > strlen($this->buf)) {
      throw new RuntimeException("Некорректная позиция чтения: $off");
    }
    $this->off = $off;
  }

  /** Проверка, что впереди есть $n байт, иначе - исключение */
  public function ensure(int $n, string $what = 'данных'): void
  {
    if ($n < 0) {
      throw new RuntimeException('Отрицательная длина чтения');
    }
    if ($this->off + $n > strlen($this->buf)) {
      throw new RuntimeException(sprintf(
        'Не хватает %s: нужно %d, в буфере осталось %d',
        $what, $n, $this->remaining(),
      ));
    }
  }

  public function readBytes(int $n): string
  {
    $this->ensure($n);
    $s = substr($this->buf, $this->off, $n);
    $this->off += $n;
    return $s;
  }

  public function readU8(): int
  {
    return ord($this->readBytes(1));
  }

  public function readU16(): int
  {
    return unpack('n', $this->readBytes(2))[1];
  }

  public function readU32(): int
  {
    return unpack('N', $this->readBytes(4))[1];
  }

  /**
   * Чтение доменного имени с поддержкой compression pointers.
   * После указателя позиция чтения встаёт сразу за ним (2 байта),
   * само имя дочитывается по месту, на которое указатель ссылается.
   */
  public function readName(): string
  {
    $buf  = $this->buf;
    $max  = strlen($buf);
    $off  = $this->off;
    $labels = [];
    $end  = null;   // куда встать после имени в исходном потоке
    $jumps  = 0;

    while (true) {
      if ($off >= $max) {
        throw new RuntimeException('Имя выходит за границы сообщения');
      }
      $len = ord($buf[$off]);

      if ($len === 0) {             // конец имени
        $off++;
        break;
      }

      if (($len & 0xC0) === 0xC0) {       // compression pointer
        if ($off + 1 >= $max) {
          throw new RuntimeException('Обрезанный compression pointer');
        }
        if ($end === null) {
          $end = $off + 2;        // 2 байта тратит сам указатель
        }
        if (++$jumps > 128) {
          throw new RuntimeException('Зацикливание compression pointers');
        }
        $ptr = (($len & 0x3F) << 8) | ord($buf[$off + 1]);
        if ($ptr >= $off) {
          throw new RuntimeException('Указатель указывает вперёд или на себя');
        }
        $off = $ptr;
        continue;
      }

      if (($len & 0xC0) !== 0) {
        throw new RuntimeException("Некорректная длина метки: $len");
      }
      if ($off + 1 + $len > $max) {
        throw new RuntimeException('Метка выходит за границы сообщения');
      }

      $labels[] = substr($buf, $off + 1, $len);
            $off += 1 + $len;
    }

    $this->off = $end ?? $off;
    return implode('.', $labels);
  }
}
```

## Перевод существующих классов на DnsReader

Логика везде та же, меняется только способ доступа к байтам - больше никаких `substr($msg, ...)` и ручных арифметик вида `$off - $rdLen` (с ридером они не нужны: он читает по всему сообщению, указатели разрешаются естественно).

```php
/* ---------- DnsRdata: контракт + совместимый враппер ---------- */

abstract class DnsRdata
{
  abstract public function serialize(): string;

  /** Чтение RDATA из ридера, стоящего на начале RDATA (ридер - над всем сообщением) */
  abstract public static function fromReader(DnsReader $r, int $rdLen): static;

  abstract public function __toString(): string;
  abstract public function toJson(): string;
  abstract public static function fromJson(string $data): static;

  /** Старый интерфейс - сохранён для совместимости с существующими тестами */
  public static function deserialize(string $msg, int $off, int $rdLen): static
  {
    $r = DnsReader::of($msg, $off);
    $start = $r->tell();
    $obj = static::fromReader($r, $rdLen);
    if ($r->tell() - $start > $rdLen) {
      throw new RuntimeException('RDATA прочитано больше, чем заявлено в RDLENGTH');
    }
    return $obj;
  }

  public function serializeWith(NameTable $table, string &$buf): void
  {
    $buf .= $this->serialize();
  }
}

      throw new RuntimeException("Некорректная длина A-записи: $rdLen");

}

  {
    $texts  = [];
    $consumed = 0;

  }

/* ---------- DnsHeader ---------- */

final class DnsHeader
{
  // свойства, serialize(), toJson(), fromJson(), rcodeName() - без изменений

  public static function deserialize(string $buf): self
  {
    return self::fromReader(DnsReader::of($buf));
  }

  public static function fromReader(DnsReader $r): self
  {
    $id  = $r->readU16();
    $flags = $r->readU16();
    $qd  = $r->readU16();
    $an  = $r->readU16();
    $ns  = $r->readU16();
    $ar  = $r->readU16();

    return new self(
      id:    $id,
      qr:    (bool)(($flags >> 15) & 1),
      opcode:  ($flags >> 11) & 0xF,
      aa:    (bool)(($flags >> 10) & 1),
      tc:    (bool)(($flags >> 9)  & 1),
      rd:    (bool)(($flags >> 8)  & 1),
      ra:    (bool)(($flags >> 7)  & 1),
      z:     (bool)(($flags >> 6)  & 1),
      ad:    (bool)(($flags >> 5)  & 1),
      cd:    (bool)(($flags >> 4)  & 1),
      rcode:   $flags & 0xF,
      qdCount: $qd,
      anCount: $an,
      nsCount: $ns,
      arCount: $ar,
    );
  }
}

/* ---------- DnsQuestion ---------- */

final class DnsQuestion
{
  // свойства, serialize(), serializeWith(), toJson(), fromJson() - без изменений

  /** @return array{0:self, 1:int} - старый интерфейс */
  public static function deserialize(string $msg, int $off = 0): array
  {
    return self::fromReader(DnsReader::of($msg, $off));
  }

  /** @return array{0:self, 1:int} */
  public static function fromReader(DnsReader $r): array
  {
    $name  = $r->readName();
    $type  = $r->readU16();
    $class = $r->readU16();
    return [new self($name, $type, $class), $r->tell()];
  }
}

/* ---------- DnsRecord ---------- */

final class DnsRecord
{
  // свойства, serialize(), serializeWith(), opt(), toJson(), fromJson(), __toString() - без изменений

  /** @return array{0:self, 1:int} - старый интерфейс */
  public static function deserialize(string $msg, int $off = 0): array
  {
    return self::fromReader(DnsReader::of($msg, $off));
  }

  /** @return array{0:self, 1:int} */
  public static function fromReader(DnsReader $r): array
  {
    $name  = $r->readName();
    $type  = $r->readU16();
    $class = $r->readU16();
    $ttl   = $r->readU32();
    $rdLen = $r->readU16();

    $start = $r->tell();
    $rdata = RdataRegistry::classFor($type)::fromReader($r, $rdLen);
    if ($r->tell() - $start > $rdLen) {
      throw new RuntimeException("RDATA типа $type прочитано больше заявленной длины");
    }

    $record = new self($name, $type, $class, $ttl, $rdata);

    if ($type === 41 && $rdata instanceof OptRecord) {
      $rdata->udpSize  = $class;
      $rdata->extRcode = ($ttl >> 24) & 0xFF;
      $rdata->version  = ($ttl >> 16) & 0xFF;
      $rdata->do     = (bool)(($ttl >> 15) & 1);
    }

    return [$record, $r->tell()];
  }
}

/* ---------- DnsMessage ---------- */

final class DnsMessage
{
  // остальное - без изменений

  public static function deserialize(string $buf): self
  {
    $r    = DnsReader::of($buf);
    $header = DnsHeader::fromReader($r);

    $questions = [];
    for ($i = 0; $i < $header->qdCount; $i++) {
      [$question] = DnsQuestion::fromReader($r);
      $questions[] = $question;
    }

    $sections = ['answers' => [], 'authority' => [], 'additional' => []];
    foreach (['answers' => $header->anCount, 'authority' => $header->nsCount, 'additional' => $header->arCount]
          as $key => $count) {
      for ($i = 0; $i < $count; $i++) {
        [$record] = DnsRecord::fromReader($r);
        $sections[$key][] = $record;
      }
    }

    // хвостовые байты (если есть) игнорируем - допускается паддинг
    return new self($header, $questions, $sections['answers'], $sections['authority'], $sections['additional']);
  }
}
```

## Что изменилось по сути

- **Один источник истины для границ.** Раньше каждый класс сам нарезал `substr` и мог промахнуться с арифметикой смещений; теперь вся проверка <данных хватает / не хватает> - в `DnsReader::ensure`, и ошибка всегда одна и та же по форме: <нужно N, осталось M>.
- **Арифметика с `$off - $rdLen` ушла.** MX, SOA, SRV раньше вычисляли позицию имени внутри RDATA вручную. Теперь ридер стоит на начале RDATA, читает фиксированные поля по порядку, а `readName()` сам разбирает и литералы, и указатели - компактность этих классов заметно выросла.
- **Совместимость сохранена.** Все `deserialize(string $buf, ...)` остались с прежними сигнатурами и стали тонкими обёртками над `fromReader` - весь ваш накопленный набор тестов (золотые векторы, roundtrip, JSON, сжатие) проходит без правок. Прямой вызов `fromReader(DnsReader ...)` - это путь для новых тестов и для потокового разбора.
- **Две новых защиты бесплатно.** Проверка <RDATA потребила не больше заявленного> в `DnsRecord::fromReader` и допущение хвостовых байтов после сообщения (паддинг легален, обрезка - нет).
- **Сериализация не тронута.** `serialize()`, `serializeWith()` и вся JSON-ветка работают поверх уже собранных объектов, ридер им не нужен.

Если захотите пойти дальше по этой линии, следующий естественный шаг - зеркальный `DnsWriter`, который аккумулирует байты записи и берёт на себя патч RDLENGTH из `serializeWith`. Скажите, если нужно.
