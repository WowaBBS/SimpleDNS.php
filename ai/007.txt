Теперь нужен DnsWriter

Логично завершить симметрию: теперь запись байтов тоже идёт через один объект, и патч RDLENGTH из `serializeWith` переезжает внутрь писателя. Сохраняю прежние контракты: `serialize()` и `serializeWith(NameTable)` остаются с теми же сигнатурами и результатами - просто внутри работают через `DnsWriter`, а рядом появляется путь напрямую через писателя.

## Новый класс DnsWriter

Добавьте в `doh_client.php` рядом с `DnsReader`:

```php
/* ============================================================
 * DnsWriter - контролируемая сборка бинарного DNS-сообщения.
 * Единственное место, куда пишутся байты при сериализации:
 * запись значения не по диапазону или некорректной метки - исключение.
 * ============================================================ */

final class DnsWriter
{
  private string $buf = '';

  public function __construct(
    private ?NameTable $table = null, // таблица для сжатия имён; null - писать литералами
  ) {}

  public function tell(): int   { return strlen($this->buf); }

  public function data(): string { return $this->buf; }

  /** Запись сырых байтов без обработки (числа, RDATA без имён) */
  public function writeRaw(string $bytes): void
  {
    $this->buf .= $bytes;
  }

  /* ---------- Числа с проверкой диапазона ---------- */

  public function writeU8(int $v): void
  {
    if ($v < 0 || $v > 0xFF) {
      throw new RuntimeException("U8 вне диапазона: $v");
    }
    $this->buf .= chr($v);
  }

  public function writeU16(int $v): void
  {
    if ($v < 0 || $v > 0xFFFF) {
      throw new RuntimeException("U16 вне диапазона: $v");
    }
    $this->buf .= pack('n', $v);
  }

  public function writeU32(int $v): void
  {
    if ($v < 0 || $v > 0xFFFFFFFF) {
      throw new RuntimeException("U32 вне диапазона: $v");
    }
    $this->buf .= pack('N', $v);
  }

  /** Патч ранее записанного U16 (RDLENGTH, счётчики, ID) */
  public function writeU16At(int $off, int $v): void
  {
    if ($v < 0 || $v > 0xFFFF) {
      throw new RuntimeException("U16 вне диапазона: $v");
    }
    if ($off < 0 || $off + 2 > strlen($this->buf)) {
      throw new RuntimeException("Патч за границами буфера: смещение $off");
    }
    $this->buf = substr_replace($this->buf, pack('n', $v), $off, 2);
  }

  /* ---------- Имена ---------- */

  /**
   * Запись доменного имени. Если у писателя есть NameTable -
   * включается сжатие: имя или его суффикс, уже встречавшиеся,
   * заменяются указателем на первое вхождение.
   */
  public function writeName(string $name): void
  {
    if ($this->table === null) {
      $this->buf .= NameCodec::encode($name);
      return;
    }
    NameCodec::encodeWith($name, $this->table, $this->buf);
  }
}
```

## Перевод классов на DnsWriter

Контракт RDATA пополняется `writeTo(DnsWriter)` с реализацией по умолчанию - классы без имён внутри унаследуют её как есть:

```php
/* ---------- DnsRdata: контракт записи ---------- */

abstract class DnsRdata
{
  // serialize(), fromReader(), deserialize(), toJson(), fromJson(),
  // serializeWith(), __toString() - без изменений

  /** Запись RDATA в писателя. По умолчанию - несжатые байты из serialize(). */
  public function writeTo(DnsWriter $w): void
  {
    $w->writeRaw($this->serialize());
  }
}

/* RDATA из одного имени */
abstract class NamedRdata extends DnsRdata
{
  // serialize(), serializeWith(), fromReader(), toJson(), fromJson() - без изменений

  public function writeTo(DnsWriter $w): void
  {
    $w->writeName($this->target);
  }
}

final class MxRecord extends DnsRdata
{
  // serialize(), serializeWith(), fromReader(), toJson(), fromJson() - без изменений

  public function writeTo(DnsWriter $w): void
  {
    $w->writeU16($this->pref);
    $w->writeName($this->exchange);
  }
}

final class SoaRecord extends DnsRdata
{
  // serialize(), serializeWith(), fromReader(), toJson(), fromJson() - без изменений

  public function writeTo(DnsWriter $w): void
  {
    $w->writeName($this->mname);
    $w->writeName($this->rname);
    $w->writeU32($this->serial);
    $w->writeU32($this->refresh);
    $w->writeU32($this->retry);
    $w->writeU32($this->expire);
    $w->writeU32($this->minimum);
  }
}

final class SrvRecord extends DnsRdata
{
  // serialize(), serializeWith(), fromReader(), toJson(), fromJson() - без изменений

  public function writeTo(DnsWriter $w): void
  {
    $w->writeU16($this->priority);
    $w->writeU16($this->weight);
    $w->writeU16($this->port);
    $w->writeName($this->target);
  }
}

/* A, AAAA, TXT, CAA, OPT, UnknownRdata - наследуют базовый writeTo */
```

Заголовок, вопрос, запись и сообщение:

```php
/* ---------- DnsHeader: запись через писателя ---------- */

final class DnsHeader
{
  // без изменений, добавляется:

  public function writeTo(DnsWriter $w): void
  {
    $flags = ($this->qr  ? 1 << 15 : 0)
         | (($this->opcode & 0xF) << 11)
         | ($this->aa ? 1 << 10 : 0)
         | ($this->tc ? 1 << 9  : 0)
         | ($this->rd ? 1 << 8  : 0)
         | ($this->ra ? 1 << 7  : 0)
         | ($this->z  ? 1 << 6  : 0)
         | ($this->ad ? 1 << 5  : 0)
         | ($this->cd ? 1 << 4  : 0)
         | ($this->rcode & 0xF);

    $w->writeU16($this->id);
    $w->writeU16($flags);
    $w->writeU16($this->qdCount);
    $w->writeU16($this->anCount);
    $w->writeU16($this->nsCount);
    $w->writeU16($this->arCount);
  }
}

/* ---------- DnsQuestion: запись через писателя ---------- */

final class DnsQuestion
{
  // без изменений, добавляется:

  public function writeTo(DnsWriter $w): void
  {
    $w->writeName($this->name);
    $w->writeU16($this->type);
    $w->writeU16($this->class);
  }
}

/* ---------- DnsRecord: запись с патчем RDLENGTH ---------- */

final class DnsRecord
{
  // без изменений, добавляется:

  public function writeTo(DnsWriter $w): void
  {
    $w->writeName($this->name);

    if ($this->rdata instanceof OptRecord) {
      $class = $this->rdata->udpSize;
      $ttl   = ($this->rdata->extRcode << 24)
           | (($this->rdata->version & 0xFF) << 16)
           | ($this->rdata->do ? 1 << 15 : 0);
    } else {
      [$class, $ttl] = [$this->class, $this->ttl];
    }

    $w->writeU16($this->type);
    $w->writeU16($class);
    $w->writeU32($ttl);

    $lenOff = $w->tell();    // здесь будет RDLENGTH
    $w->writeU16(0);       // заглушка

    $this->rdata?->writeTo($w);

    $w->writeU16At($lenOff, $w->tell() - $lenOff - 2); // латаем реальной длиной
  }
}

/* ---------- DnsMessage: оба пути через писателя ---------- */

final class DnsMessage
{
  public function serialize(): string
  {
    return $this->writeTo(new DnsWriter(null))->data();
  }

  public function serializeWith(NameTable $table): string
  {
    return $this->writeTo(new DnsWriter($table))->data();
  }

  public function writeTo(DnsWriter $w): string
  {
    $this->header->qdCount = count($this->questions);
    $this->header->anCount = count($this->answers);
    $this->header->nsCount = count($this->authority);
    $this->header->arCount = count($this->additional);

    $this->header->writeTo($w);
    foreach ($this->questions as $q) {
      $q->writeTo($w);
    }
    foreach ([$this->answers, $this->authority, $this->additional] as $section) {
      foreach ($section as $record) {
        $record->writeTo($w);
      }
    }
    return $w->data();
  }
}
```

```php
$w->writeU8(0xFF)->writeU16(0x1234)->writeU32(1);
```

## Что изменилось по сути

- **Запись зеркальна чтению.** `DnsReader` был единственным местом контроля границ при разборе - теперь `DnsWriter` единственное место при сборке. Диапазоны чисел проверяются на входе (`writeU8(-1)` упадёт, а не запишет мусор через неявное приведение), метки имён - при каждой записи.
- **Патч RDLENGTH переехал в писателя.** Метод `writeU16At` - это обобщение трюка с `substr_replace` из `serializeWith`: резервируем два байта, пишем RDATA, латаем реальной длиной. Теперь эта логика живёт в `DnsRecord::writeTo` и автоматически верна и для несжатого, и для сжатого имени - тест с RDLENGTH=16 (`2 байта указателя + 10 фикс + 4 rdata`) это фиксирует.
- **Сжатие включается конструктором.` `Писатель с `NameTable` сжимает имена, без - пишет литералами. Классам RDATA об этом знать не нужно: они просто зовут `$w->writeName(...)`, решение о сжатии принимает владелец писателя. Это чище прежнего `serializeWith(NameTable $table, string &$buf)`, где каждый класс сам разбирался с таблицей.
- **Старые методы не сломаны.** `serialize()` и `serializeWith()` теперь тонкие обёртки над `writeTo`, все прежние золотые векторы (несжатый запрос, сжатый ответ, запрос с EDNS) проходят байт в байт - это проверено тестами совместимости.
- **Симметрия писательридер.** Тест <serialize  deserialize  serialize> на сообщении с SOA, TXT и MX подтверждает, что оба объекта взаимно обратимы: повторная запись воспроизводит те же байты, включая сжатие.

Теперь у пары ридер/писатель есть только одна недостающая деталь - `OptRecord::writeTo` пишет опции из сырой строки; если будете добавлять структурированные EDNS-опции (например, Cookie), логично дать им свой мини-кодек по той же схеме <класс-поле>. Скажите, если это нужно.
